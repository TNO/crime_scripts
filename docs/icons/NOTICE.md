# PAX built-in icon catalogue

Except for the Noun Project SVGs listed below, the catalogue contains original PAX Crime Scripting repository artwork or user-contributed artwork authorized for publication under the repository MIT license. Source SVGs for user-contributed icons are retained in `packages/gui/src/assets/icons/`.

Earlier original artwork is retained for the non-scene catalogue icons, including money laundering and illegal dumping. Scene-specific multi-symbol pictograms remain replaced by single-subject artwork at their existing keys, so previously saved bundles continue to resolve the same keys. Their source templates and mappings are in `packages/gui/scripts/rework-composite-icons.mjs`.

The following Noun Project images are used under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/) (CC BY 3.0), **not** the repository's MIT license.
