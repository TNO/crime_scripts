# PAX built-in icon catalogue

All icons in this directory are original PAX Crime Scripting repository artwork by the PAX Crime Scripting contributors. They are distributed under the repository MIT license. No Noun Project or other third-party artwork is included in this catalogue.

Every SVG was normalized and optimized with SVGO 4.0.0 using `packages/gui/svgo.config.mjs`. Machine-readable provenance is recorded in `catalogue.json`.
